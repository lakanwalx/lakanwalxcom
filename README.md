# Lakanwalx

Premium personal-brand website for Mohammad Jalal Lakanwal, built with semantic HTML, Tailwind CSS, and vanilla JavaScript.

## Preview

Open `index.html` directly, or serve the folder with any static web server.

## Tailwind development

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev` while editing.
4. Run `npm run build` before publishing.

The compiled `assets/css/style.css` is included, so visitors and GitHub Pages do not need Node.js.

## Publish on GitHub Pages

Upload the full contents of this folder to the repository root, then select the repository branch in **Settings → Pages**.

The live site uses root-level `style.css`, `app.js`, `logo.svg`, `profile.jpg`, and `social-card.png` files. Make sure these five files appear beside `index.html` in GitHub. This flat structure prevents missing-folder problems when uploading through GitHub's web interface.

The supplied profile image is already included. Update any social links that are still future placeholders before launch.
